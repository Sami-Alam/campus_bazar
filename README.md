# Campus Bazar – Web Prototype

**El Senor Production**

An interactive HTML/CSS prototype of the Campus Bazar e-commerce platform.

## How to View

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
2. Navigate between pages using the links in the navbar and buttons.

## Pages Included

| File                      | Description                                      |
|---------------------------|--------------------------------------------------|
| `index.html`              | Home / Marketplace landing page                  |
| `shop.html`               | Product listing + filters                        |
| `product.html`            | Product detail page                              |
| `cart.html`               | Shopping cart + coupon                           |
| `wishlist.html`           | Customer wishlist                                |
| `checkout.html`           | Checkout + campus pickup + coupon                |
| `account.html`            | Customer orders + payment verification           |
| `student-dashboard.html`  | **Student Dashboard** – orders, wishlist, course recommendations, activity |
| `faculty-dashboard.html`  | **Faculty Dashboard** – material requests, faculty coupons, office supplies |
| `seller-dashboard.html`   | **Seller Dashboard** – listings, incoming orders, earnings & payouts |
| `admin.html`              | Admin dashboard (orders, earnings, management)   |

## Design System

- **Primary**: `#FF8C42` (Light Orange)
- **Background**: `#FFF8F0`
- **Soft Orange**: `#FFE4C4`
- **Typography**: Inter
- **Border Radius**: 12–16 px
- **Focus**: Human-Computer Interaction (clean navigation, clear hierarchy, campus-specific features)

## Features Demonstrated

### Student Dashboard
- Overview stats (orders, wishlist, coupons, items sold)
- Recent orders with payment verification
- Course-based product recommendations (e.g. CSE 3rd Year)
- Recent activity feed
- Quick switch to Seller mode

### Faculty Dashboard
- Material / office supply request system (priority levels)
- Faculty-exclusive coupons
- Recommended office supplies
- Printing & binding shortcuts
- Department context

### Seller Dashboard
- Total earnings + available payout
- Incoming orders (mark ready, message buyer, confirm handover)
- Active / Draft / Sold listings management
- Sales analytics snapshot
- Switch between Buyer and Seller modes

### Customer Side
- Browse by category (Books, Notes, Electronics, Stationery, Printing, Hostel…)
- Search bar
- Add to Cart / Wishlist
- Product detail with condition, quantity, campus pickup points
- Coupon application
- Order management + payment verification (invoice + transaction code)

### Admin Side
- Dashboard with Total Earnings, Pending & Completed Orders, Customers
- Recent orders table with status badges
- Quick actions for Products, Coupons, Categories, Bundles

## Notes

- This is a **static prototype** (no real backend).
- All interactions are front-end only (links between pages).
- Fully responsive (works on mobile too).
